网络状态「红绿灯」— 决策参考与迭代过程

三部分：Part 1 WiFi 状态行位置三方案对比（结论：开关下方，后演进为锚定已连接网络）；Part 2 连接质量图标语言（结论：全系统三格 bars）；Part 3 迭代时间线。注：Part 1/2 中的示意图保留决策当时的样式，最终样式以 Demo 文件为准。

Part 1 · WiFi 状态行位置：三方案对比

绿灯态（网络良好）

三个方案在绿灯下都成立，差异不大——这也说明不能只用绿灯态做决策。

红灯态（网络较差）— 决定性场景

弱网时状态行需要扩展为「较差 · 点按检测 ›」来引导用户行动。三个方案的扩展能力差异在这里拉开。

利弊对比

方案优点缺点结论
A · 开关上方 进页第一眼可见，有「页面级状态摘要」的气质 与「常见问题 ›」两个小字行叠放，头部拥挤；红灯态两个带箭头的可点行相邻，入口混淆；语义上离它描述的「已连接网络」最远——状态说的是下面那个网络，却放在最上面 备选
B · 胶囊内部 零额外行数，最紧凑；状态与 WiFi 概念绑定直观 绿点紧贴开关，极易被误读为「WiFi 已开启」的重复指示灯；一个胶囊两个交互目标（点状态 / 拨开关），热区冲突、误触率高；红灯态无扩展空间——放不下文案和箭头，弱网引导能力为零；WiFi 关闭时点消失，胶囊内容跳动 不推荐
C · 开关下方 语义正确：紧邻「我的网络」，状态描述的就是已连接的那个网络；视觉动线自然（开关 = 控制 → 状态 = 结果 → 列表 = 对象）；独立整行热区，无误触；红灯态有完整扩展空间（文案 + 箭头）；WiFi 关闭时整行隐藏、页面无跳动 多占一行垂直空间（约 52px）；不在首屏最顶部 推荐

推荐 C（开关下方），核心理由是红灯态。绿灯时三个方案都成立，但这个功能真正的服务对象是弱网用户：B 在红灯时只剩一个无法解释自己的红点，直接失去引导能力，应排除；A 的问题是和「常见问题」抢头部空间且语义错位，若未来「常见问题」入口移走，A 可重新纳入考虑。C 多占的一行，在 WiFi 关闭时会隐藏，实际成本很低。

Part 2 · 连接质量图标语言：圆点 vs 三格 bars

0 · 前提：两个概念，两个字形

概念含义字形出现位置
本地信号强度设备 ↔ 路由器的 RSSI，取决于摆放距离WiFi 扇形弧线，格数 = 强度网络详情页（ⓘ）
与服务器的连接质量设备 ↔ 上课服务器的综合网速（RTT / 丢包 / 带宽）本页讨论对象：圆点 or 阶梯三格磁贴角标 / 课中角标 / 状态行 / 手机端

两者经常背离：信号满格、宽带被占满时，本地信号极好而连接质量很差。所以它们必须是两个独立的视觉系统——这是下面所有结论的出发点。

1 · 磁贴角标三方案（backup 论证）

测试场景取「信号满格 + 宽带拥塞 → 质量红灯」这一背离场景，看每个方案是否说谎。

A · 图标不动 + 角标点已采纳

图标保持开关语义（白底 = 已开），角标点叠加质量信息。背离场景下不说谎：图标照常，红点报质量。绿灯时点消失，「出现即异常」。

B · 弧格填充度表质量否决

背离场景必须二选一：满格红（左，用户困惑：满格为什么红）或降格显示（右，谎报信号，诱导用户白挪设备）。弧格的既定语义是 RSSI，借用必然误导。

C · 图标整体染色不推荐

与磁贴的开关语义打架（染色易被读成「WiFi 没开好」）；白底上黄色对比度不足；且只有颜色一个通道，色盲不可读。

2 · 服务器连接质量：圆点 vs 三格 bars

同一颜色体系（绿 / 黄 / 红），比较两种字形载体。三格 bars 的形态参考视频会议 app（Zoom / 腾讯会议）的通话质量指示。

圆点（现方案）

极简、占位小。但只有颜色一个编码通道：小尺寸 / 强光 / 色盲场景下三档难以区分；黄点和红点在余光里几乎一样。

三格 bars（建议采纳）推荐

格数 + 颜色双通道编码：3 格绿 / 2 格黄 / 1 格红。颜色失效时格数仍可读；阶梯形与 WiFi 扇形天然区分（阶梯 = 链路质量，扇形 = 本地信号）；视频会议用户零学习成本。

灰度测试——色盲 / 强光下用户实际看到的东西：

圆点 · 灰度

三档几乎不可分。

4 · 结论

结论（已定稿）：颜色体系不变（绿 / 黄 / 红三档），图标载体全系统统一为三格 bars（3 格绿 / 2 格黄 / 1 格红），无例外——控制中心磁贴不用角标位圆点，改为 WiFi 图标右侧并排小型 bars（评审提出圆点会破坏一致性，采纳）。理由：① 格数 + 颜色双通道编码，色盲 / 强光 / 小尺寸下仍可读；② 阶梯形与 WiFi 扇形天然区分，正好承载「本地信号 vs 服务器链路」的概念拆分；③ 视频会议 app 已建立「阶梯条 = 本次连接质量」的用户认知，零学习成本；④「绿灯隐藏、出现即异常」规则不变；⑤ 圆点与摄像头设备上「录制中 🔴」指示灯语义冲突——红色圆点极易被误读为正在录制，bars 无此歧义。
