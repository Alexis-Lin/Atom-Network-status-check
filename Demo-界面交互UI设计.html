附 · 设计规范标注（以绿灯结果页为例，全部页面同规则）

  1. 结论区：小号 bars（格高 9/15/21px）+ 标题 32px——标题文字用灯色着色，是页面的主视觉锚点；最外围 3px 灯色细环同步着色作氛围强化（仅结果页；失败态无环、标题保持白色）。
  2. 报告卡表头：一行两端对齐，15px——日期时间居左永不截断，SSID 居右弹性截断（尾部省略号，间距 ≥ 2 字符）；卡片 = 1.5px 描边（白 14%）、5px 锐利圆角、无填充。
  3. 波形：↓ 下行灰白 #F2F5F6 / ↑ 上行淡蓝 #8FC2F5（中性数据色、无语义倾向；红黄绿仍禁用——三色专属灯语义）；折线 1.6px、样本点 r1.9（每点 = 一次 TRTC 回调，约 2–3s）、不做平滑插值；底部 1px 0 Mbps 基线（白 22%）。
  4. 时间轴：15px 真实秒数刻度（结果页 = 本次实际耗时；检测中 = 预估总时长，超出右端扩展）。
  5. 四指标：单位写全在列标题（延迟 ms / 丢包 % / ↓下行 Mbps / ↑上行 Mbps），数值 24px 加粗裸数字、等宽字体；按阈值独立着色：延迟 50/150ms、丢包 2/8%、带宽为期望的 100%/60%（下 2.0M 上 1.5M）。
  6. 操作区文案：影响（24px 白）+ 建议（24px 灰）各固定一行（中文 ≤14 全角 / EN ≤30 字符），四态固定高度——绿灯为正向文案「可以放心上课」。
  7. 按钮：左槽恒「重测」（描边线框）、右槽恒「OK / 前进」（实底浅灰 #4A545A，红灯为 WiFi 图标）；样式绑定动作、位置四态一致；无彩色按钮——红黄绿只属于灯。

字号三档制：32（结论）/ 24(数值·文案·按钮) / 15(元信息)；档内层级用字重与颜色表达。颜色只出现在四处：结论标题、超标指标、bars 灯色、结果页最外围 3px 环。

附 · 设计规范标注（课中穿透式抽屉）

  1. 容器（穿透式）：宽 360px、贴底，可见高 ≈ 156px（双行驻留形态 ≈ 190px）；顶部两角 r50 完整可见。几何约束「圆角圆心距屏心 + 半径 ≤ 233px」下三个变量互相制衡：半径↑ 需 宽度↓ 或 高度↑——**取舍定稿：宽度不妥协（文字区优先），以单行可见高 142→156 换 r50**；底边与两侧下段延伸出圆屏外、被圆缘裁掉；背景 rgba(26,31,34,.97)，无描边。
  2. 内容行：mini bars（灯色，报告卡同款 ×0.8）+ 单行文案 24px（≤10 全角），横向居中、纵向居可见区中部（距顶约 48px）；红档文案只说方向（「你的 / 课程画面可能卡顿」），「较差」由红色 bars 表达。
  3. 动效：单行轻提示升起 0.45s（ease-out）→ 停留约 2s → 收回 0.45s（ease-in），全程贴底平移、不改形状；冷却 300s、每课 ≤2 次（恢复提示不计入）。双行驻留形态：同一容器长高至可见高 ≈ 190px（事件行 + 蓝色进度行），重连 / 重试期间常驻至成功或升级——中度提示不再居中霸屏。

位置语义：所有课中提示共用底部容器——单行抽屉 = 轻度瞬时（约 2s 即收）→ 双行驻留 = 中度（重连 / 重试中常驻，不霸屏中央）→ 全屏 = 阻断；任意时刻屏上最多一个提示组件。课中无独立常驻角标——bars 永远随容器出现。动效演示见课中章节（循环播放）。
