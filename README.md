# ATOM 网络状态「红绿灯」— 方案仓库

解决的问题：**用户连上 WiFi 但上课仍卡顿**——设备只显示「已连接」，用户无法感知网速、无法归因、被课中弹窗打断。本方案 = 一套红绿灯状态机（三格 bars：3 绿 / 2 黄 / 1 红）+ 一个网速测试小程序 + 课中提示收敛，覆盖 ATOM 设备端与手机 App。

## 核心设计原则（一屏速览）

1. **位置即语义**：灯挂在它描述的对象上——WiFi 页挂在已连接网络下，手机端挂在用户画面上；
2. **绿灯静默、出现即异常**：正常状态不加任何噪音；
3. **主按钮 = 最短解决路径**：绿 → 完成，黄 → 重测，红 → 去 WiFi 设置；「重试 / OK」类按钮全部移除；
4. **不为检测挤占上课带宽**：常驻只用轻探测（约 35 KB/小时），真测速仅用户触发且课中互斥；
5. **不用旧结论冒充现状**：样本超 5 分钟过期，宁可显示「检测中…」；灯色不跨 WiFi 继承；
6. **课中不打断**：除非真断线且自动重连失败，否则一律角标 / 横幅 / 自动消失 toast。
